# Fetch Data Display

This is a native Android application built in Java as part of the Fetch Rewards Android Engineer Apprentice coding exercise.

The app fetches JSON data from a remote endpoint, filters out items with blank or null names, groups them by `listId`, and sorts the items by `name` within each group. The grouped and sorted data is then displayed in a clean, scrollable list.

---

## 📱 Features

- Retrieves data from a public JSON endpoint
- Filters out entries with blank or null names
- Groups items by `listId`
- Sorts items within each group by `name`
- Displays grouped and sorted data in a user-friendly interface

---

## 🛠 Tech Stack

- Android SDK
- Java
- Retrofit
- RecyclerView
- ViewModel + LiveData
- Material Design components
